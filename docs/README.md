# Documentation

Dokumen project utama berada di root blueprint. Folder ini berisi artefak kerja tim:

```text
docs/
├── phase-0/     # scope lock, keputusan proyek, manual actions
├── backlog/     # initial backlog + sprint plan + CSV import Jira
├── sprint/      # (dibuat saat sprint) notes planning/review/retro
└── evidence/    # (dibuat saat sprint) screenshot Jira, Vercel, Supabase, QA
```

Catatan:

- Jangan menaruh secret/screenshot berisi token di folder ini.
- Evidence deployment dan Scrum dikumpulkan sebelum Phase 6 (presentasi).
